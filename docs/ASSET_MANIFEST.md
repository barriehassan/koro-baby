# Task 01 asset manifest

Original images generated using the built-in image-generation tool on 2 November 2026. WebP encoding only was applied for delivery; no artwork was taken from external portfolios. Source PNGs remain in the session's generated_images folder; production WebP copies are in public/assets.

## Courtyard — public/assets/courtyard.webp

Brief: wide landscape illustrated everyday Sierra Leonean coastal courtyard, ochre plaster houses, blue timber shutters and veranda posts, terracotta pots, mango canopy, warm afternoon light, empty central patio, no people, table, text, logos or interface. Welcoming hand-painted animated-film/editorial style. The uploaded mockups guided the art direction. This is fictional illustrative scenery, not a verified location.

## Avatar atlas — public/assets/avatars.webp

Brief: ten equally sized portrait cells in a 5×2 atlas, centred waist-up Sierra Leonean adults, warm ivory background, consistent friendly hand-drawn animated-film style, navy outlines, rich brown skin. Top row: Hassan (curly hair/beard, green shirt), Mariama (braided bun, hoops, amber blouse), Mohamed (curls, blue shirt), Fatmata (rust headwrap, orange outfit), Ibrahim (glasses, cropped hair, ivory shirt). Bottom: Aminata (long braids, purple blouse), Sorie (yellow shirt), Kadiatu (natural puff, teal blouse), Alusine (locs, navy shirt), Hawa (green headwrap, coral blouse). No role uniforms or text.

The atlas is positioned with CSS; images are not individual user uploads. Each player has one simulated saved preset configuration in src/model.ts. The same preset is used everywhere, including chat and dialogs. Hair/outfit fields describe the fixed preset; independent part mixing, alternative poses and persistent account saving are future work. Table avatars are portrait cards, not fully rigged seated bodies. No historical identities are represented.

The wordmark is provisional live text, based on the selected navy/green/amber direction. It is not a final vector logo. The table, folded-paper decorations and notebook-paper panel are CSS-native graphics; iconography is Lucide.
